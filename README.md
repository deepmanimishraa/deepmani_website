## 🌐 Deploy to Render (Free)

### Step 1 — Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: Deepmani personal website"
git remote add origin https://github.com/YOUR_USERNAME/deepmani-website.git
git push -u origin main
```

### Step 2 — Create Render Services
1. Go to [render.com](https://render.com) → New → **Blueprint**
2. Connect your GitHub repo
3. Render will auto-detect `render.yaml` and create:
   - ✅ Free Web Service (Flask app)
   - ✅ Free PostgreSQL database

### Step 3 — Set Environment Variables
In Render Dashboard → Your Web Service → **Environment**:

| Key | Value |
|---|---|
| `SECRET_KEY` | (auto-generated by render.yaml) |
| `DATABASE_URL` | (auto-linked from render.yaml) |
| `CLOUDINARY_CLOUD_NAME` | From cloudinary.com dashboard |
| `CLOUDINARY_API_KEY` | From cloudinary.com dashboard |
| `CLOUDINARY_API_SECRET` | From cloudinary.com dashboard |
| `GEMINI_API_KEY` | From [aistudio.google.com](https://aistudio.google.com) |
| `MAIL_USERNAME` | your_gmail@gmail.com |
| `MAIL_PASSWORD` | Gmail App Password (16 chars) |
| `ADMIN_EMAIL` | deepmani@pramaniik.com |

### Step 4 — Get Gmail App Password
1. Gmail → Settings → Security → **2-Step Verification** (enable)
2. Security → **App Passwords** → Select app: Mail
3. Copy the 16-character password → paste as `MAIL_PASSWORD`

## 🎨 Customization Guide

### Profile Picture
Upload your photo to Cloudinary, copy the URL, then add to `config.py`:
```python
PROFILE_IMAGE_URL = "https://res.cloudinary.com/your_cloud/image/upload/..."
```
Then pass it to the template in `routes/main.py`:
```python
return render_template('index.html', ..., profile_image_url=app.config.get('PROFILE_IMAGE_URL'))
```

### Social Links
Edit `templates/index.html` — find the `.hero-social` section and replace `href="#"` with your actual URLs.

### Color Theme
Edit `static/css/style.css` → `:root` variables. The theme is fully token-based.

### Admin Password
Login to Admin Panel → Edit the admin user, or run in Flask shell:
```python
from models import Admin, db
admin = Admin.query.first()
admin.set_password('your_new_password')
db.session.commit()
```
